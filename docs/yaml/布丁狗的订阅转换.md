# 布丁狗的订阅转换（YAML）

- 源文件：[`yaml/布丁狗的订阅转换.yaml`](../../yaml/布丁狗的订阅转换.yaml)
- 脚本等价版：[`javascript/布丁狗的订阅转换.js`](../../javascript/布丁狗的订阅转换.js)

## 用途

轻量覆写：重建策略组、挂常用 rule-providers，按业务分流到 PROXY / AIGC / Telegram / Google，国内直连。

## 策略组

| 名称 | 类型 | 作用 |
|------|------|------|
| PROXY | select | 总入口：AUTO + 各地区 AUTO |
| AUTO | url-test | 全节点测速（排除流量/到期等杂项名） |
| AIGC | select | AI 相关，默认 SG/JP/US AUTO |
| Telegram | select | TG 域名 + IP |
| Google | select | Google 域名 + IP |
| HK / SG / JP / US AUTO | url-test | 按地区名过滤节点 |
| GLOBAL | select | 全局可选总览组 |

节点过滤：

- `include-all: true`
- `exclude-filter`: 排除 `GB|Traffic|Expire|Premium|频道|订阅|ISP|流量|到期|重置` 等

## rule-providers（摘要）

| key | 来源倾向 | 出站 |
|-----|----------|------|
| private | Meta geosite private | DIRECT |
| bing / copilot / bard / openai / claude | blackmatrix7 | AIGC |
| steam | blackmatrix7 | PROXY |
| telegram_domain / telegram_ip | Meta | Telegram |
| google_domain / google_ip | Meta | Google |
| geolocation-!cn | Meta | PROXY |
| cn_domain / cn_ip | Meta | DIRECT |

规则顺序（先匹配先生效）：

1. private → DIRECT  
2. AIGC 相关集合  
3. steam → PROXY  
4. Telegram / Google  
5. 非 CN 地理 → PROXY  
6. CN 域名/IP → DIRECT  
7. MATCH → PROXY  

## 修改提示

- 改 AIGC 默认地区：编辑 `AIGC.proxies`。
- 加业务组：先加 `proxy-groups`，再加 provider + `rules` 一行。
- CDN 前缀当前为 `testingcf.jsdelivr.net`，失效可换成其他 jsDelivr/GitHub 镜像。
