# 添加直连规则（YAML）

- 源文件：[`yaml/添加直连规则.yaml`](../../yaml/添加直连规则.yaml)

## 用途

最小示例：用 `+rules` 在配置前追加几条域名直连，不改策略组、不动 DNS。

## 内容

```yaml
# 添加直连规则示例

+rules:
  - "DOMAIN-SUFFIX,baidu.com,DIRECT"
  - "DOMAIN-SUFFIX,tencent.com,DIRECT"
```

## 怎么扩

按 Clash 经典规则语法继续加行，例如：

```yaml
+rules:
  - "DOMAIN-SUFFIX,example.com,DIRECT"
  - "PROCESS-NAME,some.exe,DIRECT"
  - "DOMAIN-SUFFIX,need-proxy.com,PROXY"
```

出口名（`DIRECT` / `PROXY` / 自定义组）必须在最终配置里存在。

## 和 Rules 列表的区别

| 方式 | 适合 |
|------|------|
| 本文件逐条写 | 临时、极少规则 |
| `Rules/*.list` + rule-providers | 规则多、要复用/热更新 |
