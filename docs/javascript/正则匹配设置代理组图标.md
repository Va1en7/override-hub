# 正则匹配设置代理组图标（JavaScript）

- 源文件：[`javascript/正则匹配设置代理组图标.js`](../../javascript/正则匹配设置代理组图标.js)

## 用途

遍历 `proxy-groups`，用正则匹配组名，写入 `icon` URL。不改节点、不改规则。

## 配置项

```js
const iconMap = [
  {
    reg: /Google/,
    url: "https://testingcf.jsdelivr.net/gh/Koolson/Qure@master/IconSet/Color/Google_Search.png",
  },
  // 继续加 { reg, url }
];

const keepOrigin = true; // true：已有 icon 则跳过
```

## 行为

1. 无 `proxy-groups` → 原样返回。  
2. `keepOrigin && group.icon` → 跳过该组。  
3. 按 `iconMap` 顺序匹配，命中第一个就 `break`。

## 扩展示例

```js
const iconMap = [
  { reg: /Google|谷歌/, url: "https://.../Google_Search.png" },
  { reg: /Telegram|电报/, url: "https://.../Telegram.png" },
  { reg: /AI|OpenAI|Claude/, url: "https://.../OpenAI.png" },
  { reg: /美国|US|🇺🇸/, url: "https://.../US.png" },
];
```

## 注意

- 正则不要写太宽，避免「美国」组被 `/美/` 之类误伤（按你 map 顺序自行约束）。
- 图标源常用 Koolson/Qure、Orz-3/mini；CDN 挂了换域名即可。
