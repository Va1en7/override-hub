# 布丁狗的订阅转换（JavaScript）

- 源文件：[`javascript/布丁狗的订阅转换.js`](../../javascript/布丁狗的订阅转换.js)
- YAML 对照：[`yaml/布丁狗的订阅转换.yaml`](../../yaml/布丁狗的订阅转换.yaml)

## 用途

脚本版轻量覆写：在 `main(config)` 里**重写** `proxy-groups`、合并 `rule-providers`、重写 `rules`，逻辑与同名 YAML 对齐。

## 入口

```js
function main(config) {
  config["proxy-groups"] = [ /* PROXY / AUTO / AIGC / ... */ ];
  config["rule-providers"] = Object.assign(config["rule-providers"] || {}, { /* ... */ });
  config["rules"] = [ /* ... */, "MATCH,PROXY" ];
  return config;
}
```

## 与 YAML 版差异

| 项 | JS | YAML |
|----|----|------|
| 合并方式 | 代码赋值，groups/rules 基本整表替换 | 客户端 YAML merge / 覆写 |
| rule-providers | `Object.assign` 保留原有再合并 | 直接写 providers |
| 适用客户端 | 支持 JS 覆写的 Mihomo 系 | 支持 YAML 覆写即可 |

策略组、规则顺序、provider URL 与 YAML 文档一致，详见 [YAML 说明](../yaml/布丁狗的订阅转换.md)。

## 修改提示

- 保留订阅原有某组：不要整表赋值 `proxy-groups`，改为 push/按名查找改。
- 调试：先 `console` 不可用时，可临时把 `config.rules` 缩成几条验证脚本是否被加载。
