### antigravity.list

用途：Google Antigravity（`agy.exe`）专有域名清单，**窄口径**。list 内不写出站，出口在引用方指定（ACL4SSR 两个 YAML 中为 `RULE-SET,Antigravity,💬 AIGC`）。

| 类型 | 值 | 备注 |
|------|-----|------|
| DOMAIN-SUFFIX | daily-cloudcode-pa.googleapis.com | 核心后端，日志命中 934 次 |
| DOMAIN-SUFFIX | aicode.googleapis.com | |
| DOMAIN-SUFFIX | antigravity.google | 官网 |
| DOMAIN-SUFFIX | antigravity-unleash.goog | feature flag；不加规则时会掉进「漏网之鱼」 |
| DOMAIN-KEYWORD | antigravity-cli-auto-updater | Cloud Run 自动更新域名 |

依据：本机 mihomo-party core 日志（2026-09-24 ~ 2026-10-09）中归因到 `agy.exe` 的 2137 条连接。

注意事项：

- **窄口径**：只收 Antigravity 专有域名。`agy.exe` 实测还会访问一批通用 Google 域名（`oauth2` / `play` / `www.googleapis` / `lh3.googleusercontent` / `www.gstatic` / `storage.googleapis`），它们被多个进程共享，**不收进本规则集**，继续按通用规则（ACL4SSR 的 `Google` / 兜底）处理；其中 `storage.googleapis.com` 还是更新包的**实际下载地址**，更新**检查**端点 `antigravity-cli-auto-updater-*.us-central1.run.app` 则在清单内。
- 实测**未出现**、已从早期版本移除的域名：`cloudcode-pa.googleapis.com`（裸）、`antigravity.googleapis.com`、`antigravity-pa.googleapis.com`、`daily-cloudcode-pa.sandbox.googleapis.com`、`cloudaicompanion.googleapis.com`、`generativelanguage.googleapis.com`。
- Playwright CDN（`playwright*.azureedge.net`）在 list 中注释保留：实测由 `RULE-SET,Microsoft` 先命中走 DIRECT 且正常，且本 RULE-SET 排在 Microsoft 之后，启用也无效。
- 通过 **GitHub raw** 拉取（`https://raw.githubusercontent.com/Va1en7/override-hub/refs/heads/main/Rules/antigravity.list`），与本仓库其它自建 list（`MyDirectRules` / `MyProxyRules`）写法一致。raw 无长缓存，推送后重新拉取覆写即生效。
- **不要改用 jsDelivr**：jsDelivr 对分支引用（`@main`）缓存 12 小时（`Cache-Control: s-maxage=43200`），实测 `purge.jsdelivr.net` 对分支引用不生效，改了规则也会持续返回旧版（曾因此把 11 条宽口径旧版发了很久）。

## 街霸 6 分流说明

当前方案：**进程直连 + RE Engine 后端走代理**（2026-10-09 恢复域名代理，采用窄口径）。

- `Rules/MyProxyRules.list` → `DOMAIN-SUFFIX,rebe.capcom.com`（订阅 rules **第 0 位**，出口 `节点选择`）：Capcom RE Engine 后端（账号 / 商店 / 钱包 / 合规）走代理。
- `Rules/MyDirectRules.list` → `PROCESS-NAME,StreetFighter6.exe`（第 1 位，出口 `全球直连`）：SF6 其余流量（对局、匹配、大厅、Steam 网络 / SDR）走直连。

历史沿革：

| 日期 | 方案 |
|------|------|
| 2026-08-20 | 新增「域名代理 + 进程直连兜底」：`streetfighter.com` / `capcom.com` / PlayFab 走 PROXY，进程其余直连 |
| 2026-08-22 | 删除域名部分（commit `0be982a`），改为现在的整进程直连 |
| 2026-10-09 | 恢复域名代理（**窄口径**）：仅 `rebe.capcom.com` 走 PROXY。依据：本机实测直连 TTFB 832–893ms，代理（香港节点）385–410ms |

说明：

- **顺序是命门**：域名代理依赖订阅 rules 顺序 —— `MyProxyRules`（第 0 位）必须排在 `MyDirectRules`（第 1 位）**之前**，否则 `PROCESS-NAME` 会先整进程直连、域名规则全部失效。
- 只影响 SF6 进程本身；其它软件仍按原配置。
- **窄口径理由**：只收 `rebe.capcom.com`。`playfabapi.com` / `playfab.com` 实测直连 TTFB 196ms，优于代理，**不收**；`streetfighter.com` / 裸 `capcom.com` 过宽，会波及非 RE Engine 的 Capcom 服务，**不收**。
- `p2p-hkg1.discovery.steamserver.net`（UDP:3478 STUN）实测直连 10–60ms、代理 140–256ms，**必须直连**，由第 1 位的进程名规则保证；**切勿**给它加代理规则。
- 不要把动态 Valve IP 写进长期 list。
- `easy_rules.yaml` 的 `path` 已对齐本仓库 `Rules/*.list`；若客户端工作目录不同，需改 path 或改工作目录映射。

## 格式

Clash classical list，一行一条，**通常不写出口组**（出口在引用它的 RULE-SET 上指定）：

```text
DOMAIN-SUFFIX,example.com
PROCESS-NAME,app.exe
IP-CIDR,1.1.1.1/32
```

## 如何挂进配置

### 方式 A：easy_rules 风格

在覆写 YAML 中：

```yaml
rule-providers:
  my_direct:
    type: file
    behavior: classical
    format: text
    path: Rules/MyDirectRules.list   # 按客户端工作目录改
  my_proxy:
    type: file
    behavior: classical
    format: text
    path: Rules/MyProxyRules.list

+rules:
  - RULE-SET,my_proxy,PROXY
  - RULE-SET,my_direct,DIRECT
```

### 方式 B：直接 +rules

规则很少时可不用 provider，把 list 内容展开成：

```yaml
+rules:
  - DOMAIN-SUFFIX,fut.gg,PROXY
  - DOMAIN-SUFFIX,futbin.com,PROXY
  - PROCESS-NAME,StreetFighter6.exe,DIRECT
  - PROCESS-NAME,FC26.exe,DIRECT
```

### 方式 C：远程 list（GitHub raw）

list 需要跨机器复用或频繁更新时，把 provider 指到仓库 raw 地址（本仓库 `Rules/antigravity.list` 即此写法）：

```yaml
rule-providers:
  Antigravity:
    type: http
    behavior: classical
    format: text
    url: https://raw.githubusercontent.com/Va1en7/override-hub/refs/heads/main/Rules/antigravity.list
    path: ./ruleset/antigravity.list
    interval: 86400

+rules:
  - RULE-SET,Antigravity,💬 AIGC
```

## 维护建议

- 若要做「域名走代理、其余直连」（如 SF6 的历史方案）：域名 PROXY 在前，同进程 `PROCESS-NAME` DIRECT 在后。  
- 同一业务直连与代理不要写反顺序。  
- `easy_rules.yaml` 的 `path` 与 `Rules/` 文件名需保持一致（现已对齐）；改文件名时同步改 path，避免静默找不到规则。
