## 街霸 6 分流说明

目标：**仅域名代理 + 进程直连兜底**（不是整进程代理）。

| 流量 | 出口 | 原因 |
|------|------|------|
| `*.streetfighter.com` / `*.capcom.com`（含 rebe）/ PlayFab | PROXY | 登录、匹配、大厅、账号站等；可用低延迟节点 |
| `StreetFighter6.exe` 其余（含 Valve `270xx` 纯 IP UDP 等） | DIRECT | 对局/Steam 网络更宜直连，避免进「漏网之鱼」 |

**引用顺序必须是先 proxy 再 direct**，例如：

```yaml
+rules:
  - RULE-SET,my_proxy,PROXY
  - RULE-SET,my_direct,DIRECT
```

若把 `PROCESS-NAME,StreetFighter6.exe,DIRECT` 写在域名代理前面，整游戏（含 capi）都会直连，域名规则失效。

说明：

- 依赖 sniffer / 域名元数据；你当前 Clash Party 日志里 capi 能显示域名，一般可用。
- 本方案只拆 SF6 进程内部；**不会**把全局 MATCH/漏网之鱼改成直连。其它软件仍按原配置。
- 不要把动态 Valve IP 写进长期 list。
- `easy_rules.yaml` 默认 path（`rules/*.list`）与本仓库 `Rules/My*.list` 文件名不一致时，需改 path 或改客户端工作目录映射。

## 格式

Clash classical list，一行一条，**通常不写出口组**（出口在引用它的 RULE-SET 上指定）：

```text
DOMAIN-SUFFIX,example.com
PROCESS-NAME,app.exe
IP-CIDR,1.1.1.1/32
```

## 如何挂进配置

### 方式 A：easy_rules 风格

在覆写 YAML 中：

```yaml
rule-providers:
  my_direct:
    type: file
    behavior: classical
    format: text
    path: Rules/MyDirectRules.list   # 按客户端工作目录改
  my_proxy:
    type: file
    behavior: classical
    format: text
    path: Rules/MyProxyRules.list

+rules:
  - RULE-SET,my_proxy,PROXY
  - RULE-SET,my_direct,DIRECT
```

### 方式 B：直接 +rules

规则很少时可不用 provider，把 list 内容展开成：

```yaml
+rules:
  - DOMAIN-SUFFIX,fut.gg,PROXY
  - DOMAIN-SUFFIX,streetfighter.com,PROXY
  - DOMAIN-SUFFIX,rebe.capcom.com,PROXY
  - DOMAIN-SUFFIX,capcom.com,PROXY
  - DOMAIN-SUFFIX,playfabapi.com,PROXY
  - DOMAIN-SUFFIX,playfab.com,PROXY
  - PROCESS-NAME,StreetFighter6.exe,DIRECT
  - PROCESS-NAME,FC26.exe,DIRECT
```

## 维护建议

- 游戏「域名走代理、其余直连」：域名 PROXY 在前，同进程 `PROCESS-NAME` DIRECT 在后。  
- 同一业务直连与代理不要写反顺序。  
- 与 `easy_rules.yaml` 默认文件名不一致时，改 path 或改文件名，避免静默找不到规则。
